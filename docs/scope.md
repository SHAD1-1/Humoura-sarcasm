# Scope — Humoura

**Product:** Humoura — a humor-based social media platform for connection and positivity.
**Live demo:** https://humoura.vercel.app/

## In Scope

**Content sharing**
- Feed: post and view humorous content from connections
- Vines: grid browsing view of content
- Likes and comments with real-time count updates
- Positivity filter: moderation to keep content positive/welcoming

**Messaging**
- Direct messaging restricted to users you follow (connection-based, privacy by design)
- Video sharing in DMs
- Real-time message delivery

**Profiles**
- Profile picture + bio customization
- Follow system (followers/following)
- Profile stats (posts, followers, following)

**Settings & privacy**
- Profile visibility and bio management
- Privacy controls: public profile, who can message, post visibility
- Notification preferences
- Account management: password change, account control

**Admin**
- User management (view/manage all users)
- User statistics
- System/platform health overview

## Out of Scope (not mentioned in agreed feature set — flag before building)
- Monetization / ads / subscriptions
- Third-party login (OAuth) beyond what's decided in stack.md
- Native mobile apps (web platform only, per live demo)
- Content types beyond posts/videos/comments (e.g. stories, live streaming)

## Notes
- Anything not listed above needs client sign-off before it's added to scope.
